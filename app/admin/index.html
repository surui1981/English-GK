拾词 · 高考英语核心词汇工具 · 面向工具订阅 + 资料电商双引擎的独立开发者方案

专治「认识却用不对」

核心闭环

发现（首页 / 失分地图） → 学习（今日任务 / 熟词僻义专项） → 付费（全包 / 资料商店），错因回流到复习队列，形成「发现 → 学习 → 诊断 → 再学」的循环。复购来自数据变好，不靠打扰。

关键设计决策

  1. 首页不叫「背单词」，叫「今日任务」。把 20 词拆成 8 分钟可完成的小目标，高三用户要的是确定性，不是词库规模。
  2. 背词卡强制翻面才可评价。三档（不认识 / 模糊 / 认识）直接喂给间隔重复算法，是留存的地基。
  3. 「熟词僻义」是唯一的差异化专项。免费用户可试 3 题，第 4 题起进入付费墙 —— 首次付费点放在最痛的地方。
  4. 失分地图把 App 从工具变成诊断。按错因归类（不是按词表），给出可解释的失分归因逻辑。
  5. 资料电商挂在词库旁边。用户刚背完词 → 立刻推配套读本，转化路径最短。
  6. 基础学习周报免费。用「看得见的进步」建立信任；完整版（深度归因 / 下周计划 / 导出）随 ¥9.9 全包解锁。
  7. 错词跨天追踪。当日错词次日优先回带进复习段，答对时给正反馈，让记忆算法从黑盒变可感知。
