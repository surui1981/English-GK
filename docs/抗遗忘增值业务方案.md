## 一、要解决的问题：不是"没记住"，是"记了就忘"

### 1.1 痛点链路

学生背词后的真实链路：

```
当天学会（当场能回忆）
  → 间隔衰减（几天后模糊）
  → FSRS 已算出"今日到期 N 词"       ← 预测层我们已经做了
  → 但没有主动触达，全靠学生自己想起  ← 关键缺口
  → 想起来复习时已忘光，重学≈重背
  → 挫败 → 放弃 → 粘性流失
```

**核心判断**：现有 FSRS 已经能算「可提取性 / 今日到期 / 高危遗忘词」，今日任务也有错词回炉——
**预测能力不是瓶颈，预测结果不被看见才是**。学生不打开 App，"今日到期 12 词"就等于不存在。

因此"对抗遗忘"和"提高粘性"是同一个问题的两面：
忘词 → 回来体验挫败 → 不再打开 → 更忘。解决遗忘就是制造回访理由。

### 1.2 三个可干预的失血点

| 失血点 | 现象 | 现状 |
| --- | --- | --- |
| 没回来 | 到期了但没打开 App | 无站内提醒入口，无通知中心（**完全空白**） |
| 回来太晚 | 想起来时已忘光 | 有 FSRS 高危词统计，但只在复盘页被动展示 |
| 复习无效 | 回来只是"看一眼" | 今日任务有检索练习雏形，未与遗忘预测联动 |

## 二、方案总览：四层干预

按"直击痛点 → 偏变现"排序，站内路线下的取舍：

| 层 | 名称 | 解决什么 | 站内路线是否做 |
| --- | --- | --- | --- |
| A | 主动触达 | 没回来 | **做站内版**：通知中心 + 首页遗忘预警卡 + 红点（不做外部推送） |
| B | 云端记忆托管 | 回来太晚 | **做**：FSRS 状态已在 `learning_state.cards` 云同步，补断更找回包与考前倒排 |
| C | 复习有效性 | 复习无效 | **做**：主动检索 + 变式语境 + 高危词自动组卷联动 |

站外推送（微信订阅消息 / 短信）本轮**不做**，但架构上预留：站内提醒的数据模型与推送共用同一份"待办事件"，未来接推送不用重做数据层。

## 三、A 层 · 站内主动触达（本轮重点）

### 3.1 待办事件模型（统一数据源）

在 `learning_state` 增加 `notices` 字段，由 FSRS 状态派生，不重复存储预测结果：

```
notices: {
  lastSeen: 时间戳,              // 上次打开 App
  dismissed: { 'due': 日期, 'risk': 日期 },  // 用户当天已忽略的提醒
  read: { 'evt_id': 时间戳 }      // 已读事件
}
```

待办事件不落库，进入 App 时现算（复用 `Store.reviewForecast()`）：

| 事件类型 | 触发条件 | 站内呈现 |
| --- | --- | --- |
| `due` | 今日到期词 ≥ 1 | 首页顶部"遗忘预警卡" + 通知中心条目 |
| `risk` | 高危遗忘词（可提取性<75%）≥ 3 | 复盘页算法卡 + 红点 |
| `comeback` | 断更 ≥ 3 天且有到期词 | 首页"快速找回包"入口 |
| `streak` | 连续打卡里程碑 | 首页成长卡庆祝 |

### 3.2 首页遗忘预警卡（最高优先级）

位置：首屏「今日任务」卡上方，插一条轻量横幅（有到期词才显示）：

```
┌────────────────────────────────────────┐
│ 🔴 12 个词快忘了 · 现在复习只要 30 秒    │
│ [立即复习]                    今天已忽略 │
└────────────────────────────────────────┘
```

- 数据：`reviewForecast().dueToday`，真实 FSRS 值，不写死。
- 动作「立即复习」：进入高危词的检索练习（不是看释义），完成后卡片自动消失。
- 「今天已忽略」写入 `dismissed.due = 今天`，当天不再打扰，次日重新出现。

### 3.3 通知中心（入口放"我的"页）

- 一个消息列表，展示近 7 天事件（到期/高危/断更召回/打卡里程碑）。
- 红点逻辑：有未读且未忽略的事件时显示，点击后按 `read` 记录清除。
- 全部由本地 FSRS 状态派生，无需服务端推送，离线也能算。

### 3.4 断更快速找回包

断更 ≥ 3 天回来，不让学生从头背：

- 取 `reviewForecast().atRisk` 的高危词，生成 10 词以内的"找回包"。
- 完成这组后回到正常今日任务，心理门槛低。
- 文案强调"只补快忘的，不用重来"。

## 四、B 层 · 云端记忆托管

### 4.1 现状

FSRS 卡片已存在 `learning_state.cards`（`sense_id → card`），随云同步——**托管基础已经有了**。
本轮补的是"基于这份数据的决策服务"：

### 4.2 考前倒排计划

结合应用已有的高考倒计时：

- 输入：考试日期、当前高危词数、每日可投入分钟数。
- 输出：未来 N 天的复习排期，把到期词均匀铺开，避免考前堆积。
- 呈现：复盘页新增"考前冲刺"标签，或首页倒计时卡下挂入口。

### 4.3 记忆资产可视化

把"记住了"变成看得见的资产，是留存的长期动机：

- 已牢固词数（`solidPct`）、累计复习次数、连续打卡天数。
- 展示为"记忆资产"卡：已永久记住 X 词 / 正在巩固 Y 词 / 高危 Z 词。
- 与 `learning_state` 同源，换设备不丢。

## 五、C 层 · 复习有效性增值

### 5.1 主动检索替代重读

抗遗忘真正有效的是"先回忆再看答案"（retrieval practice），不是反复看释义。

- 今日任务出题引擎已有选择题形式，把"高危词"优先排入检索题。
- 作答后先让学生在脑中回忆，再翻卡看答案与变体提示（现有翻卡交互可复用）。

### 5.2 变式语境联动

- 刚并入的 688 高频词变体词卡（义项变体 / 常见义干扰 / 形近词）正好是变式素材。
- 同一个词在不同搭配里重复出现，避免"只记住一个例句位置"的假性掌握。

### 5.3 高危词自动组卷

- 每天首次进入时，用 `atRisk` 词生成 5–10 题的"抢救小测"，与今日任务合并。
- 这是 A 层"遗忘预警卡"点击后的落点，形成闭环。

## 九、边界与红线

- **不写死数字**：所有到期/高危/牢固词数来自 FSRS 真实状态。
- **不虚假承诺**：不说"按此复习必定提分"，只呈现真实记忆状态与建议动作。
- **不过度打扰**：站内提醒有"今天已忽略"，断更召回有频次上限，避免引起反感。
- **权益一致**：新增能力沿用现有两档权益（¥2.9 资料包 / ¥9.9 全包），基础记忆数据对游客免费；增值功能（家长周报等）归入全包或单独评估，不悄悄加价。
- **合规**：不涉及真题原文，变式语境均为自研仿真。
