## 0. 一句话结论

**卖一本按覆盖量分档定价的《熟词僻义 100 题专项训练册》（¥1.9 / ¥3.9 / ¥4.9），
用 App 内免费 3 题做漏斗入口，用 ¥9.9 全包做工具端承接。**

训练册的骨架是实测出来的，不是拍脑袋定的：

| 事实 | 数据 |
|---|---|
| 首批 200 题里，熟词僻义（E1）只有 | 60 道，覆盖 59 个词 |
| 100 个高频词里，**一道 E1 题都没有的** | 41 个 |
| 全库 420 个义项中，**尚未出题**的 | 220 个，其中 161 个是陷阱义 |
| 结论 | 补 41 题即可让「100 题 = 100 词，每词一题」成立 |

**第二轮发现（更关键的一条）**：装配出 100 题后复核发现，
**其中 23 题的目标义项 `is_trap=false`** —— 也就是学生按自己最熟的那个义就能做对
（charge→收费、account→账户、issue→议题、major→主要的……），其中 21 题的目标义项
还是 **S1 主义项**。这类题是普通词义辨析题，不是熟词僻义题，与本册的核心承诺
「每个词只考它最容易错的那一个意思」直接冲突。

处置：**这 23 道题全部重写**（见 §3.5）。最终 100 题的目标义项 **100/100 都是陷阱义，
S1 义项 0 道**——这是本册与「词义辨析题集」的分界线，也是可机器验收的硬指标。

## 1. 产品定义

### 1.1 卖给谁

- **决策人**：高三学生本人（用书、刷题），**付费人**：家长（看进度、买资料）。
- **决策场景**：孩子月考后，阅读理解连续丢分，诊断结论是「词汇是短板」，家长需要一个**当天就能用**的东西。

### 1.2 解决什么

高考词汇丢分的主因不是「不认识」，而是**认识这个词，但按自己最熟的那个义去理解句子**。
本册只解决这一件事：给 100 个高频词各挑一个最容易错的义项，配一道题和一个能直接用的考场动作。

### 1.3 不是什么（避免货不对板）

- 不是词表（没有 1500 词的完整列表，那本是另一单品）。
- 不是刷题 App（做不了自动计时与排期，那是 App 的活）。
- 不是押题集（全书无真题原文，且**不承诺**命中率）。

## 2. 形态决策：为什么是「纸面训练册 + App 引擎」双轨

| 方案 | 能给什么 | 短板 | 结论 |
|---|---|---|---|
| 纯 PDF 训练册 | 便宜、即时交付、家长接受度高 | 无进度、无个性化、复购弱、无法按错因排期 | ✅ 主体 |
| 纯 App 专项 | 义项树、FSRS 排期、错因地图、家长周报 | 获客成本高、留存靠内容持续供给、家长难感知价值 | ✅ 引擎 |
| 双轨（**本方案**） | 纸面负责「学会」，App 负责「记住 + 归因」 | 需要两套内容保持同源 | ✅ **采用** |

**关键设计：同源不重复劳动。**
训练册的「义项速查表」按题号排，每一行就是 App 里被单独排期的那一个义项。
学生用书做完 → 在 App 里答同名专项 → App 立刻告诉他「你错的是哪一类义项」→ 生成复习词单。
书提供深度，App 提供记忆，两边数据同源，不是两套割裂的东西。

**防抵触**：买了书不等于必须再买全包。
- 训练册本身可独立使用（7 天打卡表 + 答案 + 解析，PDF 自己打印就能跑完一轮）。
- App 的免费 3 题本来就够判断「值不值得继续」。
- 全包买的是**一次性的工具端能力**（全部专项 + 义项树 + FSRS + 周报），不是解锁这一本书。

## 3. 内容规格（真实装配结果）

装配命令：

```bash
python3 tools/plan_book.py                # 规划 42 道补缺题的靶义与配额
python3 tools/plan_book_replacements.py   # 规划 23 道替换题的靶义（人工选义）
python3 tools/build_book.py               # 装配成 100 题训练册数据
python3 tools/validate_book.py            # 两层验收（补题库 + 训练册）
```

### 3.1 题目构成

| 项 | 数量 | 说明 |
|---|---|---|
| 总题量 | **100** | 首批 200 题保留 35 道 + 熟词僻义补题库 42 道 + 替换题库 23 道 |
| 覆盖词 | **100** | 每个高频词恰好 1 题，不重复、不遗漏 |
| 题源 | 首批 35 道 + 补题库 42 道 + 替换题库 23 道 | 新题独立成库，**不改首批 200 题**（它的验收配额是精确锁定的） |
| 考到的义项 | 100 个 | **全部为陷阱义（is_trap=true）**，S1 义项 0 道 |

### 3.2 难度与题型（对齐首批 200 题的同一比例）

| 难度 | 题数 | 占比 |
|---|---|---|
| 基础 | 15 | 15% |
| 中等 | 55 | 55% |
| 较难 | 30 | 30% |

| 题型载体 | C1 阅读 | C2 完形 | C3 语法填空 | C4 应用文 | C5 读后续写 | C6 七选五 |
|---|---|---|---|---|---|---|
| 题数 | 58 | 18 | 10 | 8 | 3 | 3 |

| 考到的义项层级 | S1 主义项 | S2 | S3 | S4 搭配义 |
|---|---|---|---|---|
| 题数 | **0** | 38 | 56 | 6 |

> **S1 = 0 是本册最重要的一个数字**：一道题都不考这个词最常用的那个义。
> S1 义项是学生闭着眼睛都会的，考它等于考「认识不认识」，不考任何义项辨析能力。

> 说明：现有 60 道 E1 题**全部是 C1 载体**，这是首批编排的结果。
> 补的 42 道题刻意承担了完形、语法填空、应用文、读后续写、七选五，
> 使得册子在「阅读里丢分」之外也覆盖了其他题型——这是补题带来的副产品改进。
> 23 道替换题继承被替换题的难度与载体，因此**不改变任何配额**。

### 3.3 单元结构（按词性与义项类型分，每个单元一个考场动作）

| 单元 | 主题 | 题量 | 题号 | 考场动作 |
|---|---|---|---|---|
| 单元一 | 动词的第二个意思 | 29 | 1–29 | 看宾语是「问题类名词」还是「人 / 场合」 |
| 单元二 | 名词的第二个意思 | 24 | 30–53 | 看定语与介词（a case of vs a case for） |
| 单元三 | 搭配里的那个意思 | 6 | 54–59 | 看到介词先调出整个词块 |
| 单元四 | 形容词与副词的另一个意思 | 11 | 60–70 | 先确定修饰谁、褒贬色彩 |
| 单元五 | 综合实战 | 30 | 71–100 | 把义项树摊开，逐义筛掉 |

两处需要说明的设计：

- **单元五不是兜底桶，是混编单元**：它从动词池与名词池里按占比抽出最难的 30 题
  跨词性混编。因为它的考场动作（把义项树摊开、逐义筛掉）必须跨词性才成立——
  这也正是把「选择哪个义」这件事练成本能的最后一步。
- **单元三只有 6 题，是因为词库里真正的搭配型陷阱义就这么多**：
  全库 60 个 S4 义项，其中被选为本册靶义的只有 6 个。
  题量少不是偷工，是库存就这么多——每一个都要背成永久分。

### 3.4 册内结构

```
封面 → 使用说明 + 目录（可点击）→ 5 个教学单元（题目 + 答题栏）
     → 答案速查表 → 逐题解析 → 义项速查表 → 7 天打卡表
```

| 产物 | 页数 | 说明 |
|---|---|---|
| 主册 PDF | 65 | 零空白页；目录 10 条链接全部可跳转，页码与渲染一致 |
| 免费体验样张 PDF | 4 | 3 题跨 3 个单元、覆盖 3 档难度，含完整解析 |

### 3.5 替换机制：怎么保证「每题都考陷阱义」

「每词只考它最容易错的那一个意思」如果只写在介绍页上，就只是一句宣传话。
所以把它做成了**可机器验收的硬约束**：

| 环节 | 做法 |
|---|---|
| 发现 | 装配后逐题查 `senses[].is_trap`，找出目标义项不是陷阱义的题（23 道） |
| 选义 | `tools/plan_book_replacements.py` 里有一张**人工选义表**（`TARGET_OVERRIDE`，headword → sense_id）。选义标准三条：① 学生真的会按 S1 义选它；② 该义项有 2–4 条可考的固定搭配；③ 能在 C1 阅读语境里自然造出只有它讲得通的句子。**人工判断优先于自动排序**——排序只能筛出「像陷阱义」的义项，筛不出「最好的那个陷阱义」 |
| 出题 | 23 道替换题独立成库 `data/book/e1/questions_repl_batch*.json`，靶义、难度、载体全部由 plan 指定 |
| 验收 | `tools/validate_book.py` 在 E1 层与 BOOK 层各查一次：`目标义项 is_trap=false` 直接判不合格（错误码 `E陷阱义`） |
| 不破坏配额 | 替换题**继承**被替换题的 difficulty 与 carrier，所以 15/55/30 与 C1–C6 的配额分毫未变 |

最终结果：**100 题 / 100 词 / 100 个陷阱义 / S1 义项 0 道**。
这条不变量以后每次出题都会被自动拦下——新增题库只要有一道题的靶义不是陷阱义，验收器就会红。

## 5. 付费墙落点

### 5.1 App 端（主漏斗）

```
第 1–3 题  →  免费，做完给解析 + 本机真实错因分布
第 4 题    →  付费墙：全包 ¥9.9（一次买断，含完整训练册）
解锁后     →  全部专项训练 + 义项树 + FSRS 排期 + 家长周报
```

已在原型中实测：**第 4 题准确触发付费墙**（`renderPayWallQuiz`），付费墙文案不承诺任何提分效果。

### 5.2 资料端（辅漏斗）

- 详情页提供**可下载的《免费体验 3 题》样张 PDF**（含解析），由 `tools/build_book_pdf.py` 一并生成。
- 样张的作用不是「给答案」，是让家长在 3 分钟内确认「这东西讲的是我家孩子会错的地方」。

### 5.3 为什么免费只给 3 题

- 3 题足够让学生体验到「原来我不是不认识这个词，是义项没分清」——这是转化的关键认知。
- 3 题不足以形成训练闭环，因此不构成「买了全包还得再买书」的替代关系。

## 12. 验收命令

```bash
# 1. 规划两个题库（补缺 42 + 替换 23）的靶义与配额
python3 tools/plan_book.py && python3 tools/plan_book_replacements.py

# 2. 装配成 100 题训练册（必须 100 题 / 100 词 / 100 个陷阱义）
python3 tools/build_book.py

# 3. 两层验收（内容、版权、分布、绑定、陷阱义）
python3 tools/validate_book.py

# 4. 首批 200 题验收（确认未被本轮污染）
python3 tools/validate_batch1.py

# 5. 出 PDF + 样张 + 详情页
python3 tools/build_book_pdf.py && python3 tools/build_product_page.py

# 6. PDF 质量门禁（空白页/稀疏页/HTML 残留/缺字方块/禁用词/真题出处/
#    题号齐全/解析齐全/速查齐全/目录链接可达）—— 任一不过即非零退出
python3 tools/scan_pdf_quality.py

# 7. 定价一致性门禁（5 个界面的金额必须都在白名单内，纸质档位与旧订阅制
#    表述不得复活）—— 任一不过即非零退出
python3 tools/check_pricing.py

# 8. 视觉抽检（人眼看版式，机器查不了留白与断行）
python3 tools/pdf_preview.py "output/熟词僻义100题专项训练册.pdf" /tmp/bkprev 1 2 4 21 24 65
```

> **顺序不能颠倒**：规划 → 装配 → 验收 → 回归 → 出件 → 门禁 → 抽检。
> 规划器必须是幂等的：`plan_book_replacements.py` 只读 `plan_meta.json` 的
> 首轮保留清单与源数据，**不读装配产物**——否则训练册修好之后再跑它就找不到
> 被替换的题，会把 `plan_repl_batch*.json` 覆盖成空数组。
