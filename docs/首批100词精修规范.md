## 1. 六维编码体系（照抄执行，不得自创）

### 1.1 义项层级 S（sense_level）—— 挂在义项上，不是挂在单词上

| 码 | 名称 | 判定标准 |
|---|---|---|
| S1 | 核心义 | 绝大多数语境下的第一义。**不是**「最高频义」，而是「最不会出错义」。 |
| S2 | 高考核心义 | 高考语境下高频使用，且学生容易因为有其他义项而误判。 |
| S3 | 熟词僻义 | 学生在真实语境中会认不出、被其他义项顶替的义项。**熟词僻义专项的主弹药。** |
| S4 | 搭配义 | 只在固定搭配里出现的义项，如 stand for / result in / in terms of。 |

**硬性要求**：每个词条至少 1 个 S3 义项；强陷阱词（trap_strength=3）至少 2 个 S3/S4。

### 1.2 失分机制 E（error_mech）—— 这道题「怎么错的」

| 码 | 名称 | 典型错法 | 可否挂在义项层 |
|---|---|---|---|
| E1 | 熟词僻义误判 | 认识这个词，但按最熟悉的那个义去理解句子 | 可 |
| E2 | 一词多义混淆 | 两个义都认识，语境没锁定选错那个 | 可 |
| E3 | 形近音近混淆 | 与另一词撞形/撞音导致误选（affect/effect、adapt/adopt/opt） | **不可**，见下 |
| E4 | 固定搭配缺失 | 单词都认识，搭配记不住 | 可 |
| E5 | 词性词形误判 | 词性判断错、词形变化（-ed/-ing/复数/名词化）认不出 | 可 |
| E6 | 语境推断失败 | 靠上下文推理时抓错线索 | 可 |
| E7 | 逻辑连接词误用 | 误判逻辑关系（but/however/therefore/in contrast） | 可 |
| E8 | 情感色彩误判 | 褒贬色彩、语气强度判断错 | 可 |
| E9 | 拼写变形错误 | 词形拼写/变形错误 | **不可** |
| E10 | 主题词汇缺失 | 主题话题词汇不认识 | **不可** |

**E3 / E9 / E10 的层级归属（首批 420 义项实测后定稿）**

这三条机制**不能挂在义项上**，原因是它们的失分发生在**词形层**而非**义项层**：
- E3 形近音近：错的是「选错了哪个词」，不是「理解错了哪个义」。它必须由**题目的干扰项设计**承载（干扰项取自该词的 confusable 形近/音近列表），与被考义项本身的风险无关。
- E9 拼写变形：同理，是书写层。
- E10 主题词汇缺失：是词汇广度问题，不是一个多义词的义项风险。

实测证据：420 个义项中，带 E3 标注的仅 **1 个**、带 E9 的仅 **1 个**（E10 有 27 个，但语境上多与 E1 重合）。若强行挂在义项层，配额根本无法达成。

因此本批的处理规则：
- **训练模块（题目 `module` 字段）**只设 8 个：E1 / E2 / E3 / E4 / E5 / E6 / E7 / E8。
  其中 **E3 模块由干扰项设计决定**（`design_hint` 会明确要求干扰项取自 confusable 列表）。
- **E9 归入 E5**（都是词形层），**E10 归入 E1**（都是「按熟悉的义去理解」）。
- 义项层的 `error_mech` 标注保留原样（含 E9/E10），它描述的是「这个义项本身容易被怎么误判」，与训练模块层是两个维度，不冲突。
- 「拼写变形专项」与「主题词汇专项」后续作为独立训练模块立项，不进本批 200 题。

## 2. 版权红线（逐条自检，任何一条不过则该条内容作废重写）

1. **禁止**出现真题原文、真题选项、真题解析。例句一律自编。
2. **例句 source 字段**只能写仿真来源，格式：`仿真例句 · 高考<题型/话题>高频句式`。**严禁**出现「2023 全国卷」「浙江卷」「真题」等字样。
3. **教材释义不得逐字照搬**。教材词表的 `definition_raw` / `senses_raw` 只作为义项存在性的参照，中文释义必须**自行改写措辞**（换词序、换近义词、拆句）。例如教材「n.重要议题 vi.宣布;公布」应改写为「n. 议题、争论焦点｜v. 发行、发布」。
4. **禁止**搬运牛津/朗文等词典释义原文。
5. **禁止**抓取教材正文、课文原句、单元词表原文。
6. 单词拼写与音标属事实性信息，可用（音标以教材表所载或国际音标惯例为准）。
7. 自编例句可自由使用；但**不得**写成与某道真题高度雷同的句子。

## 3. 词条 Schema

```jsonc
{
  "id": "w_case",                    // w_ + headword（非字母数字转 _）
  "headword": "case",
  "ipa": "/keɪs/",                    // 缺失则填 ""
  "level": "T1",                      // T1/T2/T3
  "pos": ["n", "v"],                  // 该词在本条中出现的词性
  "strategies": ["P2", "P4", "P8"],   // 2–4 个
  "carriers": ["C1", "C2"],           // 2–4 个
  "senses": [
    {
      "sense_id": "s_case_n_case",    // s_{headword}_{pos}_{短slug}，全局唯一
      "text": "情况、事例",            // 自行改写的中文释义，8–18 字
      "sense_level": "S2",            // S1/S2/S3/S4
      "error_mech": ["E1"],           // 1–3 个 E 码
      "is_trap": true,                // 该义项是否会被误判
      "trap_of": ["案例、病例"],       // 会被哪个义项误导
      "example": {
        "en": "...",
        "zh": "...",
        "source": "仿真例句 · 高考阅读高频句式",
        "carrier": "C1"
      },
      "collocations": ["in any case", "in that case"]   // 2–4 条
    }
  ],
  "confusable": ["caus", "casual"],  // 形近/音近/义近干扰词
  "word_family": ["case", "casual", "casually"],
  "notes": "考场判断法：……",          // 必须给「考场动作」，不是词义释义
  "quiz_ids": ["q_001", "q_002"]      // 该词对应的 2 道题 id
}
```

### 3.1 义项数量规则

- 每个词 **3–5 个义项**。
- 其中 **S1 核心义恰好 1 个**（学生绝不会错的那个）。
- S3 熟词僻义 **≥1 个**；trap_strength=3 的词 **≥2 个 S3/S4**。
- `is_trap: true` 的义项 **≥1 个**，且必须出现在 `trap_of` 里有对应说明。
- `trap_of` 写的是「**会被误判成什么**」，不是「和什么相关」。

### 3.2 notes 写法（硬性）

notes 必须写成**可执行的考场动作**，句式：

> 「考场判断法：① 看后面接的成分是【问题类名词】还是【人/场合】；② 接【问题类】→ 必是「处理、解决」义，接【人/场合】→ 才是「演讲」义。」

禁止写成：
- ❌「address 有两个意思，一是地址，二是处理问题。」——这是释义，不是动作。
- ❌「注意 address 还可以表示演讲。」——没有可执行性。

### 3.3 例句规则

- 每义项 1 句，12–28 词，句式接近高考阅读/完形的高频句式（定语从句、状语从句、被动语态、非谓语）。
- 例句必须**能明显体现该义项**，不能是「多义都能塞进去」的句子。
- 中英对应，中文用自然汉语，不要直译腔。
- 涉及具体社会事实（数据、事件）时**不要写具体数字**，避免与真题撞车。

## 4. 题目 Schema

```jsonc
{
  "id": "q_001",
  "sense_id": "s_address_v_handle",   // 必须真实存在于对应词条
  "word_id": "w_address",
  "carrier": "C1",                    // C1–C6
  "module": "E1_熟词僻义",            // 由 error_mech 主码决定
  "difficulty": "mid",                // easy / mid / hard
  "expected_accuracy": [0.35, 0.75],  // easy [0.65,0.95] / mid [0.35,0.75] / hard [0.15,0.45]
  "stem": "The new policy was introduced to ______ the widening gap between rich and poor.",
  "stem_cn": "新政策旨在______贫富之间日益扩大的差距。",
  "options": [
    {"key": "A", "text": "address", "correct": true,  "distractor_reason": null},
    {"key": "B", "text": "solve",   "correct": false, "distractor_reason": "语义近但非高考实际用词，测「是否知道高考偏好 address」"},
    {"key": "C", "text": "handle",  "correct": false, "distractor_reason": "同义干扰，测「address 是否会被误判为不可用」"},
    {"key": "D", "text": "attend",  "correct": false, "distractor_reason": "共享词根，测形近音近误判（E3）"}
  ],
  "explanation": "【考场动作】……【为什么选 A】……【其他选项】……",
  "trap_note": "陷阱来源：学生按 address＝「演讲」或「地址」去理解",
  "tags": ["E1", "E3", "P4"]
}
```

### 4.1 干扰项错因设计（标准 2 —— 本项目最硬的一条）

**每个错误选项都必须有 `distractor_reason`，且必须写「学生为什么选它」+「它测什么」。**

三种合格的干扰项类型（每题至少用到两种）：

| 类型 | 说明 | 例 |
|---|---|---|
| **语义近** | 意思相近但不是高考实际用词 | solve / handle / tackle / address |
| **形近音近** | 与目标词共享词根或形近 | attend（vs address）、adapt / adopt / opt（vs adopt） |
| **搭配错** | 词能用但搭配/介词/结构错 | （take）place vs（take）part |

**反例（不可接受）**：
- ❌ `"distractor_reason": "干扰项"` —— 没信息。
- ❌ `"distractor_reason": "不对"` —— 没信息。
- ❌ 干扰项与题干语境完全不搭（学生一眼排除）—— 那是无效干扰项，浪费一个位置。

**黄金标准**：B/C 两个选项在语义与语境上**完全说得通**，纯语感排不掉，必须靠**搭配记忆**才能定。这才是「专享」含金水所在（见 §5.2）。

### 4.2 explanation 写法（标准 5 —— 解析必须给「考场动作」）

固定三段式，缺一不可：

```
【考场动作】看到 X 时，先看 Y（判断锚点），据此锁定词义/搭配/结构。
【为什么选 A】……（结合语境说清为什么这个义项成立）
【其他选项】B 在语境里读作……，但高考实际用词/搭配是……；C 与题干搭配不成立，因为……；D 形近/音近……
```

**禁止**：只解释「A 的意思是…、B 的意思是…」。

### 4.3 本批次 200 题的分布硬指标

**数量**：每词恰好 2 题 = 200 题。

**难度**：简单 30 题（15%）／中等 110 题（55%）／困难 60 题（30%）。

**题型载体**：
| C1 阅读 | C2 完形 | C3 语法填空 | C4 应用文 | C5 读后续写 | C6 七选五 |
|---|---|---|---|---|---|
| 88 | 48 | 32 | 16 | 10 | 6 |

**失因模块**（8 个训练模块，配额精确）：
| E1 熟词僻义 | E2 一词多义混淆 | E3 形近音近混淆 | E4 固定搭配缺失 |
|---|---|---|---|
| 60 | 40 | 24 | 30 |

| E5 词性词形误判 | E6 语境推断失败 | E7 逻辑连接词误用 | E8 情感色彩误判 |
|---|---|---|---|
| 20 | 16 | 6 | 4 |

**module 命名**：`{主E码}_{E码中文名}`，例如 `E1_熟词僻义`、`E4_固定搭配缺失`。

**编排器产出的实际分布（`tools/plan_questions.py` 已配平，验收以此为准）**：
- 难度：easy 30 / mid 110 / hard 60 —— 且 **30 道 easy 全部考非陷阱义、60 道 hard 全部考陷阱义**（难度与陷阱性完全分层）

## 5. 质量标准（六条，逐条自检）

### 标准 1：义项必须真实存在且覆盖高考实际用法
每个义项都要能对应至少一种高考真实出现的用法。**不接受为凑数而造的义项**（如「interest 的第六种意思」）。

### 标准 2：干扰项必须有错因设计
见 §4.1。每题 3 个错误选项，每个都要写清「学生为什么选它」。

### 标准 3：解析必须给考场动作
见 §4.2。

### 标准 4：例句必须仿真且标注
见 §2 第 2 条。

### 标准 5：难度分布必须达标
见 §4.3。

### 标准 6：id 唯一、绑定闭合
- 词条 id 全局唯一；`sense_id` 全局唯一。
- 每道题的 `sense_id` 必须能在对应 `word_id` 的词条里找到。
- 每道题的 `word_id` 必须存在于词条表。
- 词条 `quiz_ids` 与题目 `word_id` 双向一致。
- 所有题目的 `expected_accuracy` 区间必须与 `difficulty` 匹配。
