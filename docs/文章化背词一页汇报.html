01

为什么做

背词单元从「识记」走向「迁移」
词卡里认识，回到阅读认不出→目标词放进连贯短文，先看语境再判断
熟词僻义靠死记中文释义→语境决定义项，答案必须由上下文推出
一道道孤立题，缺少完成故事→到期词自动成文，一篇有始有终的学习单元
背完就忘，复习动力靠自律→到期/高危词直接成为下一篇的选词输入

03

实现要点

app/js/article.js · s-article 页面

选词

FSRS按 due / lapses / mastery 取 3–5 词，同主题优先聚合；候选不足时用精修词补足，避免生成「只有一空」的文章。

生成

LLMstream运行时免密钥生成：取可用模型，强制流式 + 应用自管 system；只传词形/义项/主题，不传身份信息。

回流

FSRS自评 3/2/1 写入 reviewSense 或 practiceQuick，并同步 reviewFamily(article)；选对但点「犹豫」同样缩短间隔。

降级

offline无网 / 无模型 / JSON 非法 → 词库真实例句拼成离线语境包，页面明确标注「离线语境包」，不冒充 AI 生成。
