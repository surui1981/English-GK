# 拾词 · 高考英语词汇学习记忆系统（English-GK）

面向中国高考英语学生的词汇产品。核心判断：

> 学生丢分不是因为「不认识单词」，而是「不知道这个单词在语境里是哪个意思」。
> 因此产品把学习对象从「单词」下沉到「义项」，用间隔重复记住义项，用错因回流定位失分结构。

- **资料端**（`output/*.pdf`）负责「学会」：训练册、速记手册、计划打卡表。
- **App 端**（`app/`）负责「记住 + 归因」：FSRS 义项级记忆、词形发散、错因回流、全量进度可视化。
- **云端**（WorkBuddy Cloud Service）负责「持久化 + 权益 + 运营」：登录、学习状态上云、兑换码、后台管理。

## 五、产品功能地图

### 5.1 学习闭环

```
今日任务（FSRS 自动组卷）
   ├─ 新学：未学红词，必考层 / 精修词优先
   ├─ 复习：到期 / 可提取性低 / 失败过的词
   └─ 巩固：已学且稳定，维持接触防回落
        ↓ 三档自评
   FSRS 义项卡 / 词形网卡 / quickPractice 熟练度
        ↓ 答错
   错因回流（E1 僻义 / E2 多义 / E3 形近 / E4 搭配 / E5 词形 / E9 拼写）
```

- **今日任务**：20 词闭环，可切换字母顺序 / 词义相近（77 个主题语义场）/ 随机（当日稳定）；多轮可「换一批新词」或「错题回炉」，错词间隔 3–5 题再出现，单轮同词最多 2 次；进度区分本轮作答与今日累计，会话状态随云同步。
- **背单词**：选择题出题引擎，题型含僻义辨认、派生词、形近易混、词形归属、义项理解；非精修词用简化词义题 / 词性辨析题，答题结果回流到统一进度口径。
- **文章化背词**：把 3–5 个到期词/高危词写进一篇连贯短文，先通读（可展开中文大意），再逐空填词，最后按「认识 / 犹豫 / 忘了」自评；写回原有义项卡、词形网与轻量进度，并给出下一篇推荐。短文在运行时由免密钥大模型生成（强制流式 + 应用自管 system 提示词），无网或生成失败自动切到词库例句离线语境包，页面明确标注来源。入口在首页推荐区与背词页顶部，本期不设付费墙。详见 `docs/文章化背词功能方案.md`。
- **发散复习**：一个核心词带出整族派生词与形近词，一网一张 FSRS 卡片（入口位于左侧导航最下端）。
- **单词进度**：4110 词全量红绿列表 + A–Z 字母索引（每字母词数、已学数、掌握进度条），可与红绿筛选叠加。
- **专项训练**：熟词僻义 100 题、1007 核心变体词熟练度反馈（含 688 高频词按考频排序）。
- **站内触达（抗遗忘）**：首页遗忘预警卡（真实到期词数、当天可忽略）、"我的"页消息提醒中心 + 红点、断更 3 天快速找回包、高危词「先回忆再翻卡」抢救小测；全部由 FSRS 状态派生，不写死数字，离线可用。事件模型与未来微信/短信推送共用，见 `docs/抗遗忘增值业务方案.md`。

### 5.2 账号与权益

- 游客：全部学习功能开放，数据暂存本机；登录后与云端快照合并（次数/熟练度取大、首次学会时间取早、FSRS 卡按复习次数取优、日志去重），并自动续做登录前被打断的动作。
- 登录：手机号验证码 / 微信 OAuth，云端为权威数据源。
- 兑换码：不是登录凭证，是「激活码 + 展示学号」；先登录建立身份，再兑换；一码一号终身绑定，兑换即发放全包权益。
- 管理员：首位真实登录账号自动自举为管理员；后台支持批次生成、码明细筛选、作废、CSV 导出、统计。

**阶段二 · 接入真实支付与权益闭环（近期 → 中期）**

目标：把「原型支付 + 兑换码」升级为真实可收款的商业闭环。

- 接入微信支付 / 支付宝真实下单与回调，服务端校验订单、幂等发放权益，替换前端 `payAll()` 的本地写入。

- 兑换码与支付双通道统一到同一权益模型（`entitlements.all_access` + `books`），后台可区分来源。
- 退款流程与权益回收：7 天无理由退款对应的权益撤销、码回收策略。
- 付费墙 AB 测试：免费 3 题 vs 免费 5 题 vs 限时体验，以转化率数据定档。

**阶段三 · 分层变现在全包之上（中期 → 长期）**

目标：在不违背「一次买断」承诺的前提下，拓展增量收入。

- **内容增量包**：新增题型专项（语法填空易错点、读后续写高级词汇）、主题语义场专项包，作为全包用户可选的加购内容，不重复售卖已承诺的 100 题训练册。
- **个性化服务**：基于错因地图的 1 对 1 学习诊断报告、家长可读的阶段性学习解读（基础学习周报永久免费；完整版为数据化深度归因，人工解读属于全包之上的增量服务，不重复收费）。
- **机构 / 班级版**：批量兑换码管理、班级学习进度看板、教师端错因汇总；复用现有码批次与后台能力，扩展组织维度。
- **纸质联动**：训练册纸质版与 App 权益绑定（扫码激活），不做虚假划线价。

### 7.3 商业红线（延续既有约束）

1. 不做年卡月卡、续费、自动续订；最高价 ¥9.9 的既有承诺不因新功能而变质。
2. 不做划线价；单本 ¥2.9、全包 ¥9.9 是固定价格，不是「原价打折」。
3. 宣传禁用词：提分、保过、押题、押中、保证、必胜。
4. 不得编造销量、学员数、模块数量等数字。
5. 新增收费点必须先有可验证的免费价值，不得把已有免费功能改为付费。

### 7.4 客户粘性与信任机制

**粘性闭环**

- 每日任务固定 20 词，按「新学 → 复习 → 巩固」三段组卷；答对自动下一题，答错翻卡看义项并回流队尾。
- 错词跨天追踪：当日答错的词按日期归档，次日优先回带进复习段；任务卡显示「昨日错词 N 个已排进今天」，答对时给「上次错了，这次对了」正反馈。
- 收官卡：本轮结束展示真实正确率、三段构成、昨日错词攻克数、连续打卡、距高考剩余词量，可本地生成成果图（不上传、不含个人信息）。
- 高考黑卡、连续打卡、成长等级与里程碑、近 7 天新学趋势、红绿进度共同提供「看得见的进步」。
- 失分地图 → 按真实错次复习 Top10 → 回流今日任务 → 学习周报验证下周效果，形成归因到行动的闭环。
- 游客可用全部学习功能，本地暂存、登录后合并上云；注册本身免费，用来保存订单与资料凭证，算法统计作为 ¥9.9 全包的一项权益。
- 四本读本按语境 → 搭配 → 僻义 → 冲刺形成内容阶梯，2.9 元打包下载做低门槛资料分发，9.9 元全包承接需要云端同步与深度分析的用户。

**信任建设**

- 合规透明：明确「不含真题与教材原文，例句为仿真语境」，应用内与文档同时标注。
- 免费可验证：真实试读内容 + 免费 3 题 + 基础学习周报永久免费，先验证价值再付费。
- 数据真实：学习周报的学习时长、本周新学、正确率、打卡、每日柱状图与热力图全部来自 `Store` 的真实记录；薄弱项与下周行动计划按近 7 天真实错词和 FSRS 到期预测生成，不写死估算数字或虚假提分承诺。
- 算法可复核：全包后展示的记忆稳固率、可提取性、到期词数均由真实 FSRS 卡片状态现算，与复习行为同步变化。
- 周报分层透明：基础数据（时长 / 新学 / 正确率 / 打卡 / 柱状图 / 热力图）永久免费；完整版的深度归因、下周计划与报告导出均基于同一份 `rpLast` 真实快照生成，不另造数字。
- 价格诚实：一次买断、无续费、无划线价、7 天无理由退款；¥2.9 资料包与 ¥9.9 全包的权益边界在商店、详情、支付弹窗保持同一口径，明确「资料包不含云端与分析」。
- 数据归属：学习记录本地暂存 + 登录后合并，不覆盖云端已有进度；兑换码即学号可查。
- 订单永久可下载：支付或兑换成功后生成订单记录，保存在「我的 → 我的订单」；每条订单可随时下载订单凭证，链接过期也不会丢失，历史权益可下载权益凭证。
- 支付诚实：真实收款前标注为演示流程，过渡期用兑换码发放权益，避免「付款后权益不落地」。
