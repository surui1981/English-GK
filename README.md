# 拾词 · 高考英语熟词僻义训练系统（English-GK）

面向中国高考英语学生的词汇产品。核心洞察：**学生丢分不是不会背单词，而是不知道单词在语境里是哪个意思。**

- 纸面训练册负责「学会」——100 道精选熟词僻义题，靠高考固定题块（完形 / 语法填空 / 阅读）把陷阱义项顶出来。
- App 负责「记住与归因」——把同一批义项拆成最小单位（`sense_id`）挂在掌握度上，做间隔重复与错因归因。

> **仓库性质：Private。**
> 本仓库包含教材原文件（人教版单词表 `.doc` / `.xls` / 默写卡片）与由其加工而来的素材库。
> 按下方「版权与合规红线」，这些内容**禁止外传、禁止商用**。若将来要转为 Public，必须先按 `.gitignore` 末尾注释清理。

## 全链路复跑（8 步，顺序不可颠倒）

内容先行：先出题装配，再渲染物料，最后才做界面。

```bash
cd /Volumes/SSD2/经典高考单词提分

# 1-2. 规划：题量计划 + 替换题计划
python3 tools/plan_book.py && python3 tools/plan_book_replacements.py

# 3. 装配训练册数据层
python3 tools/build_book.py

# 4. 校验
python3 tools/validate_book.py && python3 tools/validate_book.py --e1
python3 tools/validate_batch1.py

# 5. 渲染商品物料
python3 tools/build_book_pdf.py && python3 tools/build_product_page.py

# 6. 渲染 App 原型
python3 tools/build_prototype_lex.py && python3 tools/build_prototype.py

# 7-8. 质量门禁
python3 tools/scan_pdf_quality.py
python3 tools/check_pricing.py
```

另有一个独立的记忆算法参考实现：

```bash
python3 tools/fsrs_reference.py
```

**幂等性约定**：`plan_book_replacements.py` 只读 `data/book/e1/plan_meta.json` 与源数据，**绝不读装配产物**。否则训练册修好后重跑会把替换计划覆盖成空数组。

## 质量门禁

每一条容易漂移的规则都做成了机器可验收的门禁脚本。

| 脚本 | 拦截什么 |
| --- | --- |
| `validate_book.py` | E1 层 + BOOK 层数据结构与配额（难度 15%/55%/30%、载体 C1–C6、义项层级、单元分布） |
| `validate_batch1.py` | 首批 100 词内容合规 |
| `scan_pdf_quality.py` | 空白页、稀疏页、HTML 残留、缺字方块、宣传禁用词、真题出处、题号齐全度、逐题解析齐全度、答案速查齐全度、目录链接可达性 |
| `check_pricing.py` | 价格金额白名单、纸质档位表述、旧订阅制表述（年卡/月卡/续费） |
| `fsrs_reference.py` | 记忆算法参考实现自检 |

门禁必须做**负向测试**——确认它不是空跑。

## 出题标准（house style）

- **掌握度挂在义项上**，`sense_id` 是最小单位。
- 目标义项必须是「陷阱义」（`is_trap=true` / `E陷阱义`）。
- 每个干扰项必须讲清两件事：**学生为什么会选它** + **它测什么 E 码**；单题至少两种干扰类型。
- 解析三段式：【考场动作】【为什么选 X】【其他选项】，不少于 120 字。
- `notes` 必须是可执行的考场动作，不是定义复述。
- 每个义项配例句与 2–4 条搭配。
- **同义干扰项是被明确认可的**——靠高考固定题块偏好定输赢，不追求「绝对唯一可解」。

## 版权与合规红线（不可协商）

1. **真题原文、选项、解析禁止商用**，任何出处标注都必须写「仿真例句 · 高考阅读高频句式」。
2. **教材释义（含旧课标）须自行改写措辞后才能对外。** 素材库里保留的原文字段仅供本仓库内部使用。
3. **词典释义不可搬运。**
4. **教材正文与单元词表禁止抓取 / 外传。**
5. 单词拼写与音标属事实性信息，可以使用。
6. **宣传禁用词**：提分、保过、押题、押中、保证、必胜。
7. **不得编造数字**：销量、学员数、划线价、模块数量（如「32 个专项」）等一律不得出现。
8. 42% 熟词生义失分率来自教培机构转述，**不得作为事实引用**。

## 技术栈与依赖

- Python 3.9+
- `reportlab` — PDF 生成
- `pypdf` — PDF 结构校验（目录锚点、链接目标）
- `pypdfium2` — PDF 渲染为图片做视觉抽检
- `xlrd` — 读取教材 `.xls` 词表
- 原型为纯静态 HTML + 原生 JS，无构建步骤

```bash
pip3 install reportlab pypdf pypdfium2 xlrd
```

### 几个容易踩的坑

- `tools/build_prototype.py` 只在 `/* @inject:fsrs */` 标记处做定点替换，词库注入写的是独立文件 `prototype/src/lex.js`——**手改 `index.html` 不会被覆盖**。
- reportlab 断行用 U+00A0（`\u00a0` 显式转义），`<nobr>` 无效。源码里直接写不可见字符极易丢失。
- `pypdf.extract_text()` 会把 U+00A0 归一化成普通空格，**不能用它验证 nbsp 是否生效**，要看实际断行结果。
- PDF 文本抽取：页眉恒为 3 行；章节标题「独立成行」；reportlab 表格逐格抽取（每格独占一行）；答案速查表题号是「整行只有数字」。
- 章节起始页判定必须排除目录页（带 `/Link` 注释的页）。
